# Rust From Zero

一套面向完全零基础学习者的中文 Rust 课程。22 课均包含教材、提前准备好的练习、自动测试和三级提示，并附带能连接本地 AI 助教的网页阅读器。

不需要学过其他编程语言。课程会从“终端是什么”“编译器为什么存在”开始，再逐步完成一个可实际使用的命令行数据工具。

## 准备环境

### 安装 Rust

访问 [rustup.rs](https://rustup.rs/)，按官方页面为你的操作系统安装。**rustup** 是 Rust 官方的安装与版本管理工具，它会一起安装：

- `rustc`：Rust 编译器，把源代码转换成能运行的程序；
- `cargo`：Rust 项目管理工具，用来编译、运行、测试代码和管理外部代码库。

安装后重新打开终端，在课程根目录运行：

```bash
rustc --version
cargo --version
```

两条命令都显示版本号，就说明基础环境已经就绪。仓库中的 `rust-toolchain.toml` 会让 Rust 自动使用课程需要的 stable（稳定）版本，并安装代码格式化和质量检查组件。

### 可选：安装 Python

只有使用网页阅读器时才需要 Python 3.10 或更新版本。阅读和完成 Rust 练习本身不依赖 Python。检查命令：

```bash
python3 --version
```

阅读器和 AI 接入只使用 Python 自带功能，不需要安装额外的 Python 包。

## 开始学习

从[课程索引](lessons/README.md)进入，第一次学习请直接打开[第一课](lessons/01-basics/README.md)。每课是一个独立的 Cargo package（由自己的 `Cargo.toml` 描述的代码单元），常用命令形式如下：

```bash
cargo run -p l01_basics
cargo test -p l01_basics
```

其中 `-p l01_basics` 表示“只处理第一课”。后续课程把名称换成该课 README 给出的 package 名即可。

源码中的 `todo!()` 表示留给学习者实现的部分。实现前，相关行为测试失败或演示程序在遇到 `todo!()` 时停止，都是预期现象；测试文件无法编译、文件缺失或 README 命令不存在则不是。

每课建议按这个顺序学习：

1. 阅读本课 `README.md`，先完成代码预测题；
2. 修改本课 `src/` 中的练习脚手架；
3. 运行本课给出的测试命令，根据诊断修改；
4. 卡住时按顺序查看 `HINTS.md` 的三级提示；
5. 完成主练习后，继续做已经提供脚手架和测试的课后巩固任务。

## 网页阅读器与 AI 助教

在课程根目录运行：

```bash
python3 viewer/serve.py
```

打开 <http://127.0.0.1:8000>。网页可以浏览全部 Markdown 讲义，右侧终端可以启动本机已安装的 AI 助手。

- **Kimi Code**：仓库已提供助教配置和当前章节读取工具，安装、登录并信任本仓库后即可使用；
- **Claude Code**：仓库提供项目级配置，首次使用需批准；
- **Codex、Grok、OMP 和其他助手**：可在侧栏直接启动，按指南完成章节上下文配置或使用自定义命令。

完整的安装、K3/high 启动方式、通用 MCP（让助手读取当前章节的连接协议）配置和故障排查见[AI 助教接入指南](docs/agent-integration.md)。AI 不是学习或运行课程的必需品。


## 安全提示

AI 助教可以读取项目文件并执行本机命令。阅读器默认只监听 `127.0.0.1`（本机回环地址），且没有登录验证。不要在公共网络上开放它；确需局域网访问时，先阅读接入指南中的风险说明。
