# 第三课提示（HINTS）

卡住时按级别查看：第一级只给思考方向，第二级把问题拆小，第三级给出接近完整的结构。
尽量在看完某一级后回到代码里再试一次，而不是一次读完三级。
提示不直接给出完整答案；如果你发现自己只是在照抄第三级，先合上书用自己的话复述一遍需求再写。

## 主练习：`Note`（`src/lib.rs`）

### `new`

**第一级（思考方向）**
这个函数拿到两个字符串的**所有权**，要交出一个 `Note`。`Note` 的两个字段分别叫什么？参数的名字和字段的名字一样吗？

**第二级（局部分解）**
1. 返回类型是 `Self`，也就是 `Note` 本身，所以要构造一个 `Note` 值返回。
2. 构造 struct 的语法是 `Note { 字段名: 值, ... }`。
3. 当参数名和字段名完全相同，可以用简写：只写名字一次。

**第三级（接近完整的结构）**

```text
Self {
    title: /* 哪个参数的值放进这个字段？注意所有权要移进来 */,
    body: /* 同理，换成另一个参数 */,
}
```

---

### `title` 与 `body`

**第一级（思考方向）**
返回类型是 `&str`，而字段是 `String`。本课第十五节「为什么字符串参数通常写 `&str`」讲过：`&String` 可以自动转换成 `&str`。你需要的只是对字段做一次**借用**，而不是复制。

**第二级（局部分解）**
1. `self.title` 是 `String` 类型的字段。
2. `&self.title` 的类型是 `&String`。
3. 函数声明返回 `&str` 时，`&String` 会在返回时自动转换为 `&str`（借用范围从整个字符串开始）。

**第三级（接近完整的结构）**

```text
fn title(&self) -> &str {
    /* 借用 self.title：不复制，也不把字段移走 */
}
```

`body` 完全同理，只换字段名。

### `append_line`

**第一级（思考方向）**
行为分两种情况：正文为空时直接写入；正文非空时先补一个换行符再写入。判断“正文是否为空”和“在字符串末尾追加内容”分别需要什么？

**第二级（局部分解）**
1. `self.body` 是 `String`，可以用 `is_empty()` 判断是否为空串。
2. 追加单个字符用 `push(字符)`，追加一段文本用 `push_str(文本)`。
3. 因为 `self` 是 `&mut self`，可以直接修改 `self.body`。
4. `line` 是 `&str`，只是借用，直接把它追加进去即可，不需要也不能取得它的所有权。

**第三级（接近完整的结构）**

```text
if self.body 不是空的 {
    在 self.body 末尾 push 一个换行符 '\n'
}
在 self.body 末尾 push_str(line)
```

### `into_parts`

**第一级（思考方向）**
参数是 `self` 而不是 `&self`——方法拿走了整个 `Note` 的所有权，所以函数体内可以把字段**移出去**。返回的二元组第一个元素是标题，第二个是正文。

**第二级（局部分解）**
1. `self` 是按值拥有的，所以 `self.title`、`self.body` 都可以被 move 出来。
2. 二元组字面量写作 `(第一个值, 第二个值)`。
3. 按文档注释约定的顺序：标题在前，正文在后。

**第三级（接近完整的结构）**

```text
(/* 标题字段 */, /* 正文字段 */)
```

## 课后巩固：`text` 模块（`src/text.rs`）

### `first_line`

**第一级（思考方向）**
你要返回的是 `text` **内部**的一段，所以返回类型才是 `&str` 且不需要新建 `String`。问题的核心是：第一个 `'\n'` 出现在哪个字节位置？找到就用它切，找不到就返回全部。

**第二级（局部分解）**
1. `str` 有一个方法能找到某个字符第一次出现的字节下标：`find`，它返回 `Option<usize>`——找到了是 `Some(下标)`，没找到是 `None`。`Option` 是下一课的主角，这里只需要会用 `match` 或 `if let` 区分这两种情况。
2. 找到下标 `i` 后，用 slice 语法取 `text` 的前 `i` 个字节：`&text[..i]`。
3. 没找到时直接返回 `text` 本身。

**第三级（接近完整的结构）**

```text
match text.find('\n') {
    Some(i) => 返回 text 开头到 i（不含）的 slice,
    None => 返回整个 text,
}
```

### `total`

**第一级（思考方向）**
遍历借来的 slice，把每个元素累加到一个局部变量里。空 slice 时循环一次都不执行，累加器的初始值自然就决定了结果。

**第二级（局部分解）**
1. 声明一个可变的累加器，初始为 0。
2. `for value in values` 会依次遍历 slice 中每个元素的**引用**（`&i32`）。
3. 把每个值加进累加器；`&i32` 可以直接参与加法，也可以先解引用。
4. 循环结束后返回累加器。

**第三级（接近完整的结构）**

```text
let mut sum = 0;
for value in values {
    sum += /* 把 value 指向的整数加进来 */;
}
sum
```

### `byte_prefix`

**第一级（思考方向）**
直接写 `&text[..max_bytes]` 会在切到字符中间时 panic（README「字符串 slice 与 UTF-8」一节演示过）。你需要的工具是 `str::is_char_boundary(下标)`：它告诉你某个字节下标是否正好是字符边界。先处理“整段都要”的情况，再从 `max_bytes` 往前找最近的有效边界。

**第二级（局部分解）**
1. 如果 `max_bytes >= text.len()`，直接返回整个 `text`。
2. 否则，从 `max_bytes` 开始，用循环逐步把下标减 1，直到 `text.is_char_boundary(下标)` 为真。
3. 用这个下标切出开头一段返回。注意下标减到 0 时 0 一定是边界，循环必然结束。

**第三级（接近完整的结构）**

```text
if max_bytes >= text 的字节长度 {
    return text;
}
let mut end = max_bytes;
while text 在 end 处不是字符边界 {
    end -= 1;
}
返回 text 开头到 end 的 slice
```
