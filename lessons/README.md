# Rust 完整课程目录

本课程共 22 课，面向没有编程经验的读者。所有课的讲义、练习源码、自动测试和三级提示都已提供，不需要等到学习时再生成。

下面的英文是代码中会遇到的名称，括号先给出通俗含义；每课会结合实际问题完整解释。Cargo 是 Rust 自带的工具，用来编译（把源码转换成程序）、运行和测试代码。

## 第一阶段：程序与数据的基础

1. [Rust 程序、变量、表达式与控制流](01-basics/README.md)：认识开发工具，让程序保存数据、计算并按条件选择执行路径。
2. [`struct`、`enum`、方法与 `match`](02-data-modeling/README.md)：用结构体组合相关数据，用枚举表示有限种类，再按不同种类处理。
3. [所有权、移动、借用、字符串与切片](03-ownership-borrowing/README.md)：理解谁负责管理一份数据，以及如何在不转移归属的情况下使用它。
4. [`Option`、`Result`、自定义错误与 `?`](04-option-result/README.md)：明确表示“可能没有值”和“操作可能失败”，并逐层传递错误。

## 第二阶段：集合与工程组织

5. [`Vec`、数组与切片](05-vec-slices/README.md)：分别处理长度可变的列表、长度固定的列表和列表的一段视图。
6. [`HashMap`、`HashSet` 与 Entry API](06-hash-collections/README.md)：按键查找数据、保存不重复的值，并处理“键可能已经存在”的情况。
7. [模块、crate、package 与可见性](07-modules-crates/README.md)：把代码拆成清晰的单元，并决定哪些内容允许外部使用。
8. [测试、文档测试、Clippy 与可维护验证](08-testing-quality/README.md)：用自动检查确认程序行为，并借助 Rust 的代码审查工具发现常见问题。

## 第三阶段：复用逻辑与抽象

9. [闭包、环境捕获与 `Fn` 系列 trait](09-closures/README.md)：把可调用的一段逻辑当作值传递，并理解它如何使用周围的数据。
10. [`Iterator`、适配器与所有权模式](10-iterators/README.md)：逐项处理数据，把筛选、转换和收集组合成清晰流程。
11. [泛型、trait bound 与单态化](11-generics/README.md)：让同一份代码适用于多种类型，同时保留编译期检查。
12. [trait、关联类型、`impl Trait` 与 `dyn Trait`](12-traits/README.md)：定义不同类型共同具备的行为，并选择合适的抽象边界。

## 第四阶段：数据结构与生命周期

13. [`Box`、递归类型与动态分发](13-box-recursion/README.md)：把数据放到堆（由程序动态申请的一块内存）上，表示大小无法在编译前确定的数据结构。
14. [生命周期、生命周期省略与借用 API 设计](14-lifetimes/README.md)：说明引用（对数据的临时访问）能合法使用多久，避免访问已经失效的数据。
15. [`Rc`、`Weak`、`RefCell` 与内部可变性](15-smart-pointers/README.md)：在单线程中共享归属、避免循环引用，并在受控规则下修改共享数据。

## 第五阶段：并发、文件与异步

16. [线程、`move` 闭包与 channel](16-threads-channels/README.md)：让多个执行流同时工作，并通过消息在它们之间传递数据。
17. [`Arc`、`Mutex`、`RwLock`、`Send` 与 `Sync`](17-shared-concurrency/README.md)：安全地跨线程共享和修改数据，并理解类型如何表达线程安全约束。
18. [文件、路径、命令行参数与输入输出错误](18-files-cli/README.md)：编写能接收用户参数、读写文件并清楚报告失败的程序。
19. [`async`/`.await`、`Future` 与运行时](19-async/README.md)：处理需要等待的任务，让程序在等待期间推进其他工作，并理解执行这些任务所需的运行时支持。

## 第六阶段：元编程、系统边界与综合项目

20. [声明宏、过程宏与代码生成边界](20-macros/README.md)：在编译前按规则生成代码，同时学会判断为什么普通函数往往更合适。
21. [`unsafe`、裸指针与 FFI](21-unsafe-ffi/README.md)：理解需要程序员额外保证安全的操作，以及如何与其他语言（尤其是 C）相互调用。
22. [综合项目：可扩展的命令行数据工具](22-capstone/README.md)：综合前面的知识，完成能导入、查询、统计和导出数据的程序。

## 推荐学习方式

1. 按顺序阅读；第一次学习不要直接跳到并发、宏或 `unsafe`。
2. 先完成讲义中的代码预测，再打开本课目录中的练习源码。
3. 源码里的 `todo!()` 是留给你的任务。把它替换为自己的实现后，运行本课 README 给出的 Cargo 命令。
4. 实现前，部分行为测试失败是预期现象；如果连测试都无法编译，先检查是否漏改了类型或函数签名。
5. 卡住时按顺序查看本课 `HINTS.md` 的三级提示，不必一开始就看后面的提示。
6. 完成主练习后，再做已经提供脚手架和测试的课后巩固任务。
7. 把自己的理解写入 `notes/concepts.md`，把值得重看的错误写入 `notes/mistakes.md`。

网页阅读器可以更方便地浏览讲义，并连接本地 AI 助教；启动和配置方法见[接入指南](../docs/agent-integration.md)。
